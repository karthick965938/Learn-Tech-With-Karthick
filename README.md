# Learn Tech With Karthick

Official companion repository for the YouTube channel **[Learn Tech With Karthick](https://www.youtube.com/channel/UCYA9_YRBI0EKhktI-nhHoXQ)**. Here you will find source code, wiring notes, and project assets that go with the videos—clone a folder, open the sketch, and follow along at your own pace.

[![YouTube](https://img.shields.io/badge/YouTube-Learn%20Tech%20With%20Karthick-red?style=flat&logo=youtube)](https://www.youtube.com/channel/UCYA9_YRBI0EKhktI-nhHoXQ)

## Projects in this repository

| Project | Description |
| :--- | :--- |
| [**ESP32 handheld gaming console**](esp32_gaming_console/) | Ten arcade-style games on a 128×64 SSD1306 OLED (ESP32 DevKit V1, U8g2). |
| [**Robot face animations**](robot-face-animations/) | Board-agnostic animated eyes and mouth on OLED (ESP32, ESP32-CAM, Arduino Uno/Nano). |

## Getting started

1. Clone this repository:

   ```bash
   git clone https://github.com/<your-username>/Learn-Tech-With-Karthick.git
   cd Learn-Tech-With-Karthick
   ```

2. Open the project folder that matches the video you are following.
3. Read that folder’s `README.md` for hardware, libraries, and upload steps.

Replace `<your-username>` with your GitHub username after you create the remote repository.
